# Serene Yoga — Student Website Assignment

A responsive, front-end yoga studio website inspired by the general idea of an online yoga studio. This is an original student demo, not a copy of YogaEasy/EkhartYoga.

## How to run
1. Extract `YogaEase_Website.zip`.
2. Open the `YogaEase_Website` folder.
3. Double-click `index.html` to open it in Chrome, Edge, or Firefox.

Recommended: open the folder in Visual Studio Code and use the **Live Server** extension, then click **Go Live**.

## Features
- Responsive layout for desktop and mobile
- Navigation menu
- Yoga class cards and working category filters
- Class details pop-up
- Sample weekly schedule with choose buttons
- Join form with browser-side validation and confirmation
- No installation, API key, or server required

## Important demo note
This is a static front-end assignment. The join form does not send or save data to a database, and the schedule does not book real classes. The Google Fonts import requires internet; the site still works with fallback fonts offline.

## Files
- `index.html` — page content
- `style.css` — layout and visual design
- `script.js` — interactive features
